# Retrieve a relevant precedent

Start with the bundled [case cards](cases.md). Search for the relevant topic ID, mechanism or error; read only matching sections. Each card links a reviewed GOLD writeup from 2023 onward and records a limitation. The package works without the original database.

Useful routes: representation/transfer → 727356; missing context → 446422; downstream objective → 551688 or 744980; teacher/student errors → 711570; data alignment → 684353; distillation → 527629; uncertainty routing → 569902; candidate selection → 651671.

Sources suggest mechanisms, not mandatory recipes. Check assumptions and counterexamples. A new idea need not appear in this library. Do not confuse winner status with proof that every component helped; distinguish abandoned and post-deadline work. These selected cases do not estimate win probabilities.

If a larger corpus exists, use selective queries over `analysis_cases` or `analysis_observations` in `research.sqlite`, or matching records from `analysis-cases.jsonl`. Configure its actual path; never assume another workstation's layout. Do not load the full corpus into context.
